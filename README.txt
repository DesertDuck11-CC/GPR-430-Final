Welcome to Tic-Tac-Toe by Victor Diab and Benjamin Trudell!

To launch our game first you will need to run these commands

git submodule update --init --recursive

Afterwards, you can run the run_game.bat to launch the game
You may have to run the exe once in visual studio if this doesn't work (just run main.cpp)

Player 1 always goes first, just click to place your 'x' or 'o', when somebody
wins, Player 1 needs to hit 'Space' in order to restart the game
